# NOVA GUILD キャンペーンLP 実装課題

架空のスマートフォンゲーム「NOVA GUILD」のキャンペーンLPについて、ファーストビュー（ヒーロー部分）を実装してください。

## 課題について

- 制限時間は約60分です。
- HTML / SCSSを中心に実装してください。Sassは設定済みです。
- PC（1440px幅）とSP（375px幅）の両方に対応してください。
- 画面幅768px以下ではSPデザインに切り替えてください。
- 完成見本は `reference/`、分割素材は `public/assets/` にあります。
- 高度なJavaScriptやフレームワーク機能は必要ありません。
- 完成させること自体が目的ではありません。考え方や進め方も確認します。
- 不明点は自由に質問してください。面接官と相談しながら進めて構いません。
- インターネット検索と、普段使用しているエディタを利用できます。
- AIを利用したい場合は、事前に面接官へ確認してください。

見本と完全に同じ1px単位の再現は求めません。時間内で優先順位を考えながら進めてください。

## セットアップ

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

## 実装場所

- HTML: `src/pages/index.astro`
- 共通スタイル: `src/styles/global.scss`
- ヒーロー: `src/styles/hero.scss`

必要であれば、ファイルを追加・分割しても構いません。
